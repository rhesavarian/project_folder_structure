Clone template repo from GitHub, delete .git, and initialized new git repository. Run this code:

"""
git clone https://github.com/rhesavarian/project_folder_structure.git <project_name> 
cd <project_name>
rmdir /s /q .git
git init
"""

Alternatively, in the folder, there should be a bat file to clone and re-initialize git folder

After cloning repo, install venv. Run setup_venv.bat, wait until process is completed

You can start run the jupyter lab from the environment using start_jupyter_lab.bat
